# 加分项勾选功能修复总结

## 问题描述

用户反馈：**从界面勾选了临床检验中心的两个加分项，提示更新成功，但刷新页面后数据丢失（显示为空）**

## 问题根源分析

### 1. 数据不一致问题

**修改前的逻辑**：
```java
// save() 方法
bonus.setDirectorPresentation(dto.getDirectorPresentation() != null ? dto.getDirectorPresentation() : 1);
// 如果前端传 0，保存为 0；如果传 null，保存为 1

// findByTaskIdAndInstitutionId() 方法
empty.setDirectorPresentation(1);
// 如果没有记录，返回 1
```

**问题**：
- 保存时：前端传 `0` → 保存为 `0` ✅
- 查询时：数据库有记录（值为 0）→ 返回实际值 `0` ✅
- **但是**：`convertToDTO()` 方法没有处理 null 值，可能导致字段丢失 ❌

### 2. 硬编码默认值干扰

**修改前**：
```java
private List<InstitutionBonusDTO> getDefaultBonuses(Long taskId) {
    // 硬编码的假数据
    String[][] data = {
        {"1", "临床检验中心", "1", "1"},
        {"2", "护理质控中心", "0", "1"},
        ...
    };
}
```

**问题**：
- 当数据库中没有记录时，会返回这些硬编码的假数据
- 导致前端显示混乱

## 修复方案

### 修复 1：统一默认值逻辑

**修改前**：
```java
// 保存时默认为 1（已勾选）
bonus.setDirectorPresentation(dto.getDirectorPresentation() != null ? dto.getDirectorPresentation() : 1);

// 查询无记录时返回 1
empty.setDirectorPresentation(1);
```

**修改后**：
```java
// 保存时默认为 0（未勾选），需要前端明确传 1 才表示勾选
bonus.setDirectorPresentation(dto.getDirectorPresentation() != null ? dto.getDirectorPresentation() : 0);

// 查询无记录时返回 0（未勾选）
empty.setDirectorPresentation(0);
```

### 修复 2：完善 DTO 转换

**修改前**：
```java
private InstitutionBonusDTO convertToDTO(InstitutionBonus bonus) {
    InstitutionBonusDTO dto = new InstitutionBonusDTO();
    BeanUtils.copyProperties(bonus, dto);
    // ... 复制其他字段
    return dto;
    // 没有处理 null 值
}
```

**修改后**：
```java
private InstitutionBonusDTO convertToDTO(InstitutionBonus bonus) {
    InstitutionBonusDTO dto = new InstitutionBonusDTO();
    BeanUtils.copyProperties(bonus, dto);
    // ... 复制其他字段
    
    // 确保字段不为 null
    if (dto.getDirectorPresentation() == null) {
        dto.setDirectorPresentation(0);
    }
    if (dto.getSecretaryParticipation() == null) {
        dto.setSecretaryParticipation(0);
    }
    return dto;
}
```

### 修复 3：移除硬编码假数据

**删除** `getDefaultBonuses()` 方法，不再提供假数据：

```java
@Override
public List<InstitutionBonusDTO> findByTaskIdWithData(Long taskId) {
    // 直接返回数据库中的数据，不添加默认值
    return findByTaskId(taskId);
}
```

## 核心改进

### 1. 分值固定，不可配置

**重要说明**：
- ✅ **主任演讲加分分值：8 分**（固定，从 application.yml 读取）
- ✅ **秘书参与加分分值：2 分**（固定，从 application.yml 读取）
- ✅ **可以配置的只是"是否勾选"**（0 或 1）

### 2. 明确的业务流程

```
1. 初始状态：所有机构都是未勾选（0）
   ↓
2. 管理员根据实际情况下拉勾选
   - 主任演讲：是/否
   - 秘书参与：是/否
   ↓
3. 保存到数据库
   ↓
4. 计算评分时自动加上对应的分值
   - 勾选主任演讲 → +8 分
   - 勾选秘书参与 → +2 分
```

### 3. 数据一致性保证

| 场景 | 修改前 | 修改后 |
|------|--------|--------|
| 无记录查询 | ❌ 返回 1（误导） | ✅ 返回 0（真实） |
| 保存 null 值 | ❌ 保存为 1 | ✅ 保存为 0 |
| DTO 转换 | ❌ 可能为 null | ✅ 保证非 null |
| 假数据干扰 | ❌ 有硬编码数据 | ✅ 只显示真实数据 |

- 不会因为刷新页面而丢失
