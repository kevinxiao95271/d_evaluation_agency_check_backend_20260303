# 分数保留两位小数功能实现总结

## 需求说明
将所有评分相关接口返回的分数统一保留小数点后两位，确保前端展示一致性和用户体验。

## 实现方案

采用 **Service 层四舍五入 + DTO 层格式化注解** 的双重保证机制：

1. **Service 层处理**：在计算和转换分数时，使用 `roundScore()` 方法统一四舍五入
2. **DTO 层注解**：添加 `@JsonFormat(pattern = "#.00")` 确保 JSON 序列化时格式统一

## 修改内容

### 1. 工具方法 - ScoreServiceImpl.java

新增 `roundScore()` 工具方法：

```java
/**
 * 保留两位小数
 */
private Double roundScore(Double score) {
    if (score == null) {
        return null;
    }
    return Math.round(score * 100.0) / 100.0;
}
```

## 技术要点

### 1. 四舍五入算法
```java
Math.round(score * 100.0) / 100.0
```
- 使用 `Math.round()` 进行四舍五入
- 乘以 100 后取整再除以 100

### 2. JSON 格式化注解
```java
@JsonFormat(pattern = "#.00")
private Double score;
```
- `#` 表示可选数字位
- `.00` 强制保留两位小数
- 即使值为整数也会显示为 `10.00`

### 3. 双重保证机制
- **Service 层**：确保业务逻辑层数据精度统一
- **DTO 层**：确保序列化输出格式统一
- 即使某一层失效，另一层仍能保证正确输出

## 注意事项

1. **null 值处理**：`roundScore()` 方法会检查 null，避免空指针异常
2. **整数显示**：整数会显示为 `10.00` 而非 `10`
3. **精度损失**：四舍五入可能导致微小误差，但对业务无影响
4. **数据库存储**：不影响数据库存储精度，仅在输出时处理
